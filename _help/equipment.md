# Equipment Guide

StrategyHub provides various equipment for members to use.

## Equipment Types

### Borrowable Equipment

Equipment that can be checked out and taken off-site:
- Cameras
- Audio equipment
- Lighting gear
- Other portable items

### Studio Equipment

Equipment that stays in the studio and is automatically included in studio bookings:
- Studio cameras
- Audio mixing boards
- Lighting systems
- Backgrounds and props

### Server Equipment

Infrastructure and servers managed by admins:
- Development servers
- Bitcoin nodes
- Network equipment

## Checking Out Equipment

1. Go to the [Resources](/dashboard/resources/) page
2. Find the equipment you need
3. Click "Request Checkout"
4. Select checkout and return dates
5. Submit your request

## Equipment Status

- **Available**: Ready to be checked out
- **Checked Out**: Currently in use
- **Maintenance**: Being serviced
- **Online/Offline**: Server status

## Studio Default Equipment

When booking studio time, default studio equipment is automatically included. You don't need to select it manually.

## Returning Equipment

Return equipment on or before the return date. Contact an admin if you need to extend your checkout period.
