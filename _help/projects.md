# Projects Guide

Projects are a way to organize and showcase your Bitcoin work on StrategyHub.

## Creating a Project

1. Go to the [Projects](/dashboard/projects/) page
2. Click "Create Project" (admin only)
3. Fill in the project details:
   - **Name**: Project name
   - **Description**: What your project does
   - **Status**: Idea, Active, Completed, or Archived
   - **GitHub Repo**: Optional link to your repository
   - **Tags**: Comma-separated tags
   - **Skills Needed**: What skills are required (rust, lightning, ui/ux, etc.)
   - **Looking for Collaboration**: Check if you want collaborators
   - **Show in Portfolio**: Check to display on the homepage

## Project Fields

### Skills Needed

List the technical skills required for your project. Examples:
- rust
- lightning
- ui/ux
- typescript
- bitcoin-core

### Collaboration

If you're looking for collaborators:
1. Check "Looking for collaboration"
2. Optionally add a note about what kind of help you need

### Portfolio

Projects marked "Show in Portfolio" will appear on the StrategyHub homepage for public viewing.

## Donating to Projects

You can support projects by donating Bitcoin via OpenNode:
1. Click "Donate" on any project
2. Enter the amount in satoshis
3. Complete payment via OpenNode

## Team Members

Project creators can add team members. Only team members and admins can edit projects.
